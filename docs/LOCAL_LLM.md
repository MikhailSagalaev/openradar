# openradar с локальной LLM

Классификатор и извлечение данных для research принимают **любой OpenAI-совместимый
HTTP API** — включая полностью локальные. Сеть для этого не нужна; без ключа и без LLM
всё работает по правилам, LLM только добавляет точность.

## Включение

```bash
RADAR_LLM_ENABLED=true
OPENAI_BASE_URL=http://127.0.0.1:11434/v1   # ollama
OPENAI_MODEL=qwen2.5:7b
OPENAI_API_KEY=ollama                        # любое непустое значение
```

- **[ollama](https://ollama.com)**: `OPENAI_BASE_URL=http://127.0.0.1:11434/v1` после `ollama serve`.
- **[LM Studio](https://lmstudio.ai)**: `http://127.0.0.1:1234/v1`.
- **llama.cpp server**: `http://127.0.0.1:8080/v1`.

Требования к модели: JSON-режим (`response_format: json_object`) и понимание русской речи —
проверены `qwen2.5` от 7B и `llama3.1` от 8B. Классификатор зовётся только для принятых
правилами лидов; таймаут 25 секунд, при ошибке пайплайн продолжает по правилам.

## Что LLM делает

- `isLead` + `confidence ≥ 0.6` — может отклонить, не может «оживить» спам;
- категория, город, навыки, оценка бюджета — заполняют пустые поля;
- research-извлечение (`RADAR_EXTRACT_ENABLED=true`): зарплата, роль, грейд из постов
  для открытого отчёта — ответ проверяется по полям, разметка страницы и правила приоритетнее модели.

## Безопасность

Текст лида передаётся модели как данные (JSON в `user`-сообщении), без инструментов и
без исполнения. Скрытые Unicode-инструкции в постах вырезаются на приёме. Ответ модели —
строгий JSON; всё остальное отбрасывается.
